# REPS2 release gates

These gates are acceptance criteria, not current status claims.

## Alpha

- ISO/ELF inspection and stable manifests.
- End-to-end static analysis, native generation, and documented native runtime execution.
- Unsupported behavior produces structured diagnostics.
- Reproducible tests and builds.

## Public beta candidate

- Installable Windows x64 application with one-ISO import.
- At least three distinct titles validated through gameplay acceptance plans.
- Required CPU, runtime, kernel, and hardware paths covered by regression tests.
- Recovery, diagnostics, documentation, and reproducible release build.

## REPS2 1.0

- Beta criteria remain satisfied.
- Evidence-backed multi-game compatibility matrix.
- No known critical correctness defects in supported gameplay paths.
- Required services match the documented compatibility matrix.
- Complete documented UX, controller workflow, packaging, clean-install testing,
  security review, performance evidence, licensing, and independent final audit.

## Current status

Alpha, public beta, and 1.0 are **not met**. See [PROJECT_STATE.md](PROJECT_STATE.md)
for verified evidence and blockers.
